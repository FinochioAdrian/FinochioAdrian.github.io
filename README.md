# finochioadrian.github.io

Sitio personal de **Adrián Finochio** — Analista de Sistemas y analista funcional.

- `index.html` — perfil personal y académico, el circuito de rendición, método de trabajo y competencias
- `aplicaciones.html` — catálogo de las ocho aplicaciones: casos de uso, estado de desarrollo, medidas y stack
- `estilos.css` — hoja de estilos compartida por las dos páginas
- `img/` — capturas de pantalla, tomadas con datos de prueba
- `cv/` — currículum en PDF, versión visual y versión compatible con ATS

Sitio estático, sin dependencias ni proceso de compilación. Las únicas fuentes externas son
las tipografías de Google Fonts.

## Publicar
**🌐 En vivo:** [https://[FinochioAdrian.github.io//](https://FinochioAdrian.github.io/)

Es un sitio de usuario de GitHub Pages: el repositorio se llama `FinochioAdrian.github.io`
y se publica solo desde la rama `main`, en la raíz. Ver `PASOS.md`.

## Privacidad

Los repositorios de los sistemas descriptos son privados: operan sobre datos fiscales y
personales de terceros dentro de un organismo público. Las capturas publicadas acá están
tomadas con datos de prueba y no contienen nombres, CUIT ni importes reales.
